# Screenshots

Drop captured PNGs here using the exact filenames below. The main
[`README.md`](../README.md) embeds them at a fixed width (`<img width="250">`)
so the gallery stays tidy regardless of device resolution.

## How to capture

1. Run the **MyProjectDemo** app (it links this package locally).
2. Open a demo from the home list, then capture the screen:
   - Simulator: **File ▸ New Screen Shot** (⌘S), or
   - Device: press the side + volume-up buttons.
3. Save/rename the file to match the table and move it into this folder.

Tip: capture in **light mode** on a recent iPhone for consistent framing. The
gallery scales every image to 250 px wide, so exact pixel size doesn't matter —
just keep aspect ratios consistent (don't crop some and not others).
